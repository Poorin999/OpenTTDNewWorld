# OpenTTD-Stock

OpenTTD 15.3 ที่แปลงเป็นเกมจำลองการเทรดหุ้น (เทอร์มินัลแบบ MT5, กระเป๋าเงินหลายใบ, ธนาคารกลาง)
GitHub Actions เป็นคนสร้างเกมให้ ไม่ต้องคอมไพล์ในเครื่อง ผลที่ได้คือไฟล์ `openttd.exe` ในส่วน Artifacts ของแต่ละรอบ

## โครงสร้างโฟลเดอร์ (แยกตามหมวด)

| โฟลเดอร์ | หมวด | ไฟล์ |
|---|---|---|
| `stock/` | ระบบหุ้น: ราคา แท่งเทียน ออเดอร์ margin เงินปันผล และคำสั่งซื้อขาย | `stock_base.*`, `stock_cmd.*` |
| `gui/` | หน้าจอ: เทอร์มินัล (Market Watch, กราฟ, Toolbox) และหน้าต่างสั่งซื้อ | `stock_gui.*`, `stock_order_gui.cpp` |
| `wallet/` | กระเป๋าเงิน: เงินสดหลัก กระเป๋าเทรด กระเป๋าเชื้อเพลิง | `wallet_base.*`, `wallet_cmd.*` |
| `bank/` | ธนาคารกลาง: กู้ คืน ดอกเบี้ย | `central_bank.*` |
| `saveload/` | เซฟและโหลดข้อมูลทั้งหมดของม็อด | `stock_sl.cpp`, `compat/stock_sl_compat.h` |
| `widgets/` | รหัสปุ่มและช่องของหน้าต่าง | `stock_widget.h` |
| `lang/` | ข้อความภาษาอังกฤษที่ม็อดเพิ่มเข้าเกม | `english_*_strings.txt` |
| `patch/` | การแก้ไฟล์ที่ OpenTTD มีอยู่แล้ว (13 ไฟล์) | `stock-market.patch` |
| `tools/` | สคริปต์ที่นำไฟล์ม็อดไปใส่ในซอร์สเกม | `apply_overlay.py` |
| `docs/` | บันทึกส่งต่องาน | `HANDOFF_OpenTTD-Stock.md` |
| `.github/workflows/` | ใบสั่งงานสร้างเกม | `build-windows.yml` |

โฟลเดอร์ย้ายไฟล์ไปมาได้โดยไม่ต้องแก้สคริปต์ เพราะ `apply_overlay.py` หาไฟล์ด้วยชื่อ แต่ชื่อไฟล์ต้องไม่ซ้ำกันในทั้ง repo (ถ้าซ้ำ สคริปต์จะหยุดและบอกชื่อไฟล์ที่ซ้ำ)

## ลำดับการสร้างเกม (ดู `.github/workflows/build-windows.yml`)
1. ดึง repo นี้ และดึง OpenTTD 15.3 ต้นฉบับ
2. ใส่ `patch/stock-market.patch` (แก้เฉพาะไฟล์ที่ OpenTTD มีอยู่แล้ว)
3. ตรวจว่าไฟล์ของม็อดไม่ชนกับไฟล์ของ OpenTTD (`apply_overlay.py --check`)
4. คัดลอกไฟล์ม็อดเข้าที่ ลงทะเบียนคำสั่ง ไฟล์ซอร์ส และข้อความภาษา (`apply_overlay.py`)
5. คอมไพล์ด้วย MSVC แล้วอัปโหลดผลลัพธ์

## เพิ่มฟีเจอร์ใหม่
1. วางไฟล์ `.cpp` / `.h` ใหม่ในโฟลเดอร์หมวดที่ตรงกัน (หรือสร้างโฟลเดอร์หมวดใหม่)
2. เพิ่มชื่อไฟล์ใน `FILES` (บอกว่าลงที่ไหนในซอร์สเกม) และ `NEW_SOURCES` ใน `tools/apply_overlay.py`
3. ถ้ามีคำสั่งใหม่ เพิ่มใน `NEW_COMMANDS` ถ้ามีข้อความใหม่ ใส่ไฟล์ใน `lang/` แล้วเพิ่มชื่อใน `STRING_FILES`

## กฎของโค้ด (ฝ่าฝืนแล้วบิลด์พังหรือเกมออนไลน์ไม่ตรงกัน)
- สถานะเกมเปลี่ยนผ่านคำสั่ง (`DEF_CMD_TRAIT`, `Command<CMD_X>::Post`) เท่านั้น หน้าจอห้ามแก้เงินหรือข้อมูลเกมตรง ๆ
- ส่วนที่เป็นสถานะเกมคำนวณด้วยจำนวนเต็มเท่านั้น ห้ามใช้เวลาจริงของเครื่อง
- คำสั่งต้องมีพารามิเตอร์อย่างน้อย 1 ตัวนอกจาก `flags` (ไม่งั้น MSVC ล่ม: ICE C1001 ที่ `command_func.h`)
- ห้ามใช้ `std::to_string` ให้ใช้ `fmt::format`
- ทุกการหาร ตัวหารต้องไม่เป็นศูนย์ (เคยทำให้เกมล่มตอนเปิดหน้าต่างเทรด)
- ปุ่มต้องไม่ใช้ `WWT_PUSHBTN` ถ้าไม่มีรูป ให้ใช้ `WWT_PUSHTXTBTN` พร้อมข้อความ
